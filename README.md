# VRS organisation profile

GitHub renders [profile/README.md](profile/README.md) at
[github.com/vrs-tudelft](https://github.com/vrs-tudelft). This repository maintains
that public entry point; it is not the website source or manuscript.

The [website repository](https://github.com/vrs-tudelft/vrs-tudelft.github.io#readme)
owns the Idea → Experiment → Findings interface. The private
[analysis](https://github.com/vrs-tudelft/virtual-radiosonde#readme),
[data](https://github.com/vrs-tudelft/vrs-data#readme) and
[manuscript](https://github.com/vrs-tudelft/vrs-paper#readme) repositories own their
technical instructions and provenance. Manuscript prose remains in Overleaf.

Keep the profile concise, link current destinations, and describe the research
question and evidence without implying independently validated urban retrieval.
Preview Markdown and verify links before merging a profile change. Organisation
and repository descriptions/homepage links are separate GitHub metadata.
